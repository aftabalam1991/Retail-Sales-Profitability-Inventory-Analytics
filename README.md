# Retail Sales, Profitability & Inventory Analytics

## Project Overview
This project analyzes retail sales, profitability, returns, and inventory performance using Python and Jupyter Notebook.

## Business Objectives
- Analyze overall sales performance
- Measure profitability across products and stores
- Identify sales trends
- Analyze product returns
- Monitor inventory performance
- Identify high and low performing stores/products

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- CSV Data Analysis

## Dataset
The project uses multiple datasets:

- Sales Data
- Product Master
- Store Master
- Returns Data
- Monthly Inventory Data

## Analysis Performed
- Data Cleaning
- Data Validation
- Data Transformation
- Sales Analysis
- Profitability Analysis
- Store Performance Analysis
- Product Performance Analysis
- Returns Analysis
- Inventory Analysis
- Trend Analysis
